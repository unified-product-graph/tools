# Contributing to `@unified-product-graph/mcp-server`

Bug reports, pull requests, and ideas are welcome.

## Issues

Open issues at [github.com/unified-product-graph/mcp-server/issues](https://github.com/unified-product-graph/mcp-server/issues).

A good bug report includes:
- The version of `@unified-product-graph/mcp-server` you're running
- Which MCP client (Claude Code, Cursor, etc.)
- A minimal reproduction — the `.upg` snippet, the tool you called, the arguments, what you expected, what happened

## Pull requests

1. Fork the repository
2. Create a branch (`feature/short-description`)
3. Make your change with a focused commit
4. Add or update tests
5. Open the PR

Run `npm test` before pushing — the suite has to stay green.

## Repository layout

```
src/
├── server.ts          MCP server bootstrap
├── store.ts           In-memory store backed by .upg JSON
├── tools/             Tool handlers (one file per domain)
├── lib/               Shared infrastructure
├── playbooks/         Guided creation flows
└── tooling/           Shared tool-registry contract
TOOLS.md              Auto-generated tool reference (do not edit by hand)
skills/               Bundled Claude Code skills shipped with the package
```

`TOOLS.md` is regenerated by `npm run generate-tools` after a build. Don't hand-edit it — change the JSDoc on the handler in `src/tools/<domain>.ts` instead.

## Releases

This package co-versions with `@unified-product-graph/core` and `@unified-product-graph/cloud-server`. Cutting a release happens centrally; PR authors don't need to bump the version.
